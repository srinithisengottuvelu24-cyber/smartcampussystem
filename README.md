Smart Campus Complaint Management System

A simple full-stack web application for managing college campus complaints
Language used
JavaScript
CSS
Axios
Python
Django
Django REST Framework
SQLite

User Roles

Student — Register, login, submit, view, search, filter, edit and delete complaints
Maintenance Staff — View assigned complaints, update status and add resolution remarks
Admin — View, search, filter, assign, update and delete complaints

Features
Complaint CRUD
Search and filtering
Complaint status tracking
Staff assignment
Dashboard
Form validation
